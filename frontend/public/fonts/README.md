# Geist Sans

Unmodified variable WOFF2 from Vercel's official Geist distribution, tag `v1.7.2`.

- Source: https://github.com/vercel/geist-font/blob/v1.7.2/fonts/Geist/webfonts/Geist%5Bwght%5D.woff2
- Product: https://vercel.com/font
- License: `Geist-OFL.txt` (SIL Open Font License 1.1, copied from the same tag).
- Size: 69,760 bytes; upright weights 100–900. The browser synthesizes italics where requested.

Self-hosted and preloaded by `index.html`; `font-display: swap` retains readable fallback text. No font npm/Next.js dependency. Financial monospace remains the system font. This file is a separate font transfer and is not included in the JavaScript/CSS gzip budget totals.
